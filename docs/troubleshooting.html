Recap Troubleshooting

Quick checks for the most common problems with the Recap Chrome extension.

Recap does not show my LeetCode status or streak

Recap reads your signed-in LeetCode session, so make sure you are signed in to LeetCode in the same Chrome profile where Recap is installed. Then reopen the Recap popup.

I am not getting reminder notifications

  • Open Recap's settings and confirm that notifications are enabled and a reminder time is set.
  • Check that Chrome notifications are allowed in your operating system settings.
  • Reminders stop once the Daily Challenge is completed, so a solved challenge will not trigger a retry.

Chrome will not load the extension

  • Make sure Developer mode is turned on at chrome://extensions.
  • Unzip the download first, then choose the extracted dist folder in Load unpacked.
  • If you built from source, run the build again and select the newly generated dist folder.

For the full steps, see the installation guide.
