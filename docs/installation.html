Installation guide

Install the Recap Chrome Extension

Download Recap from GitHub and install it in Chrome using Load unpacked. You can be up and running with LeetCode Daily Challenge reminders in a few steps.

Version 0.2.1

Download Recap

Download the Recap v0.2.1 ZIP directly from the official GitHub release.

Download Recap v0.2.1

The download is a ZIP file. Unzip it before installing the extension.

Install Recap with Chrome Load Unpacked

Chrome lets you install an unpacked extension while Developer mode is enabled. Follow these steps:

  1. Download and unzip Recap. Use the download button above and extract the ZIP file to a folder on your computer.
  2. Open Chrome's extensions page. Enter chrome://extensions in the Chrome address bar.
  3. Enable Developer mode. Turn on Developer mode using the switch in the top-right corner.
  4. Load the extension. Click Load unpacked and select the Recap dist folder.
  5. Pin Recap. Open Chrome's extensions menu and pin Recap for convenient access from the toolbar.
  6. Sign in to LeetCode. Sign in to LeetCode in Chrome, then open Recap to complete the initial setup.

Build Recap from Source

If you want to build Recap yourself, clone the Recap GitHub repository and install its dependencies.

git clone https://github.com/anshukumar2932/Recap.git
cd Recap
npm install
npm run build

After the build completes, load the generated dist folder using Chrome's Load unpacked option.

First-Time Setup

After installing Recap, open the extension settings and configure the options you want to use:

  • Your daily reminder time
  • The reminder retry interval
  • Chrome notifications
  • Your optional Codeforces handle
Need help? If something is not working after installation, see the Recap troubleshooting guide.

Recap Installation FAQ

Is Recap free?

Yes. Recap is a free and open-source Chrome extension.

Do I need Chrome to install Recap?

Yes. Recap is designed as a Chrome extension and is installed through Chrome's extensions page.

Do I need a LeetCode account?

Yes. Sign in to LeetCode in Chrome after installing Recap so the extension can check your Daily Challenge status.

Where do I find the Recap extension folder?

When installing the pre-built release, select the extracted dist folder when you click Load unpacked.
