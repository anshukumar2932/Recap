How to Install the Recap Chrome Extension

Recap is a free Chrome extension that helps you stay consistent with the LeetCode Daily Challenge by providing reminders and completion tracking. You can download the latest release from GitHub and install it using Chrome's Load unpacked option.

Download Recap

Download Recap v0.2.1 directly from the official GitHub release:

Download Recap v0.2.1

After downloading, unzip the file before installing the extension.

Install Recap with Chrome Load Unpacked

  1. Download and unzip the Recap ZIP file using the button above.
  2. Open chrome://extensions in Google Chrome.
  3. Turn on Developer mode in the top-right corner.
  4. Click Load unpacked.
  5. Select the extension's dist folder.
  6. Once Recap is installed, pin it from Chrome's extensions menu.
  7. Sign in to LeetCode and open Recap to complete the initial setup.

Build Recap from Source

If you prefer to build Recap yourself, clone the Recap GitHub repository and install its dependencies: 

git clone https://github.com/anshukumar2932/Recap.git
cd Recap
npm install
npm run build

After the build completes, load the generated dist folder through Chrome's Load unpacked option.

First-Time Setup

After installing Recap, open the extension's settings page to configure:

  • Your daily reminder time
  • The reminder retry interval
  • Chrome notifications
  • Your optional Codeforces handle
Need help? Visit the Recap troubleshooting guide if you have problems installing or using the extension.

Recap Installation FAQ

Is Recap free?

Yes. Recap is a free and open-source Chrome extension.

Do I need Chrome to install Recap?

Yes. Recap is designed as a Chrome extension and is installed through Chrome's extensions page.

Do I need to sign in to LeetCode?

Yes. Sign in to LeetCode after installing Recap so the extension can check your Daily Challenge status.
