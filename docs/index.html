Recap: LeetCode Daily Challenge Reminder for Chrome

Recap is a free, open-source Chrome extension that reminds you to solve the LeetCode Daily Challenge and shows whether you have completed it.

Add to Chrome | View on GitHub

Features

  • Today's LeetCode Daily Challenge with difficulty and topic tags
  • Completion status at a glance
  • Daily reminder notifications
  • Reminders at your chosen time, retrying every 15, 30, 60, or 120 minutes until solved
  • LeetCode streak counter and Codeforces streak tracking
  • Settings page for reminder time, notifications, and Codeforces handle

How it works

Recap reads your signed-in LeetCode session and queries the LeetCode GraphQL API. Reminders use Chrome alarms and notifications, with retries until the challenge is completed. Read the technical details.

Frequently asked questions

Does Recap send LeetCode reminders?

Yes, through Chrome notifications.

Do I need a LeetCode account?

Yes, you must be signed in to see status and streak.

Is Recap free?

Yes, it is free and open source.
